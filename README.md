# Mixmelody

Mixmelody is an interactive, component-driven music discovery web application built with React. It allows users to browse audio tracks, dynamically curate custom music playlists, and save their selections instantly.

## Tech Stack & Tools
* **Frontend Framework:** React.js
* **Language:** JavaScript (ES6+)
* **Build Tool:** Create React App / Webpack
* **Package Manager:** npm

## Repository Structure
* `src/` — Core React application source code hosting view components, state logic, and styling assets.
* `public/` — Static assets including the main HTML shell container and favicon configurations.
* `package.json` — Manages external package scripts and project dependencies.
